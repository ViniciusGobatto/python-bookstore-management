# Python Bookstore Management System

A console-based bookstore management system developed in Python as part of the QUT IFQ581 – Programming Fundamentals unit.

The program allows users to register books, organise them by category, validate input data, and save and retrieve book records from a text file.

## Features

- Object-oriented programming using a `Book` class
- Book registration and categorisation
- Input validation for book IDs, page numbers and prices
- Display of registered books
- Filtering books by category
- Saving and loading book records from a text file
